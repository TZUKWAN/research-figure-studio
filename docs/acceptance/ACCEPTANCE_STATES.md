# Acceptance States (Production Closure 2)

Single vocabulary for every acceptance matrix in this directory. The summary
statistics are generated by `scripts/generate-acceptance-summary.mjs` — never
hand-written.

| State              | Meaning                                                                                           | Counts toward Real User Execution Coverage |
| ------------------ | ------------------------------------------------------------------------------------------------- | ------------------------------------------ |
| `PASS_REAL_UI`     | Verified by operating the real desktop app (Computer Use / manual) with screenshot evidence       | yes                                        |
| `PASS_E2E`         | Verified by the Playwright Electron E2E suite (real app loop, stubbed model)                      | yes                                        |
| `PASS_INTEGRATION` | Verified by a cross-module test through the production surface (real engine/txn/IPC shape, no UI) | no                                         |
| `PASS_UNIT`        | Verified by module-level unit tests only                                                          | no                                         |
| `BLOCKED_EXTERNAL` | Blocked by an external dependency (credentials, OS, GitHub permissions)                           | no                                         |
| `NOT_IMPLEMENTED`  | Declared in design, not built                                                                     | no                                         |
| `NOT_UI_EXPOSED`   | Built and verified, but no UI entry point exists yet                                              | no                                         |
| `FAIL`             | Currently failing                                                                                 | no                                         |

Rules:

1. A `Save As` feature never clicked in the real UI is `NOT_UI_EXPOSED` or
   `FAIL` — never `PASS` "equivalent via Ctrl+S".
2. Matrices carry the CURRENT state only; historical findings live in
   `docs/audit/` working papers.
3. All summary numbers come from the generator script.
